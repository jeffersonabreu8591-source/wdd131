Website Planning Document

Fuxiquinha Style Guide

Site Name

```

Fuxiquinha Style Guide

This website is about kids fashion and different outfit ideas. The name comes from the Fuxiquinha brand that I work with as a graphic designer and helps show what the website is about.

fuxiquinhastyle.com

```

Site Purpose

```

The purpose of this website is to help parents and resellers find fashion ideas for their children or their consumers. The site will include outfit suggestions and size guides, fashion tips and a contact page to help get more information.

```

Scenarios

```
  • What are some good outfit ideas for children during summer?
  • How do I know what clothing size is best for my child?
  • Where can I find fashion tips and contact information?
```

Color Schema

```
#FF6B9A - Used for buttons, accents and some headings.
#1E3A5F - Used for the header, footer and navigation.
#F5F5F5 - Used for the page background.
```

Typography

```

Poppins - Used for titles and navigation.

Roboto - Used for paragraphs and normal text.

```
